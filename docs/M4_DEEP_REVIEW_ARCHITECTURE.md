# M4 深度主美审阅与构图诊断

日期：2026-07-28
版本：0.5.0a0

## 目标

M4 解决早期主美审阅内容过浅的问题。实现吸收竞品“多维分析、独立观察工具和
改图衔接”的产品类别，但不复制其源码、界面表达或长提示词。

## 八维审阅

`DeepArtDirectorReview` 固定覆盖：

1. 构图结构
2. 视觉引导
3. 焦点层级
4. 色彩设计
5. 明度结构
6. 灯光与氛围
7. 材质可读性
8. 世界设计与叙事

每个维度分别记录制作目标、参考图呈现、当前截图效果、证据摘要、已有优点、
风险、关联问题、可信度和不确定性。整次审阅最多五个核心问题，并输出需要保留
的内容及有依赖顺序的 UE 执行计划。

## 输入证据

审阅输入包含：

- 制作意图和当前制作阶段
- 参考图视觉简报
- 参考图与当前截图
- Oklab 色板、明度直方图、共享色板和三阶阈值
- 有界本地证据摘要
- 当前 Version 的全部成对区域及最新分析
- Shot/Version 历史和锁定目标

本地证据摘要在最长边 256 像素的工作副本上计算全图明度、P10/P50/P90、
三阶比例、溢出、彩度、中性色及九宫格明度/反差/彩度。该摘要是测量结果，
不是显著性或审美判断。

## 可靠性

AI 可以为可测结论返回归一化矩形、指标、关系、阈值和容差。本地校验器使用
原始工作图复核，结果为：测量支持、部分支持、存在冲突或无法验证。冲突会降低
可信度并显示原因，不会删除 AI 原结论。

供应商请求逐张标记 `IMAGE_ROLE=reference/current`，避免模型混淆图片身份。
深度审阅使用较大的输出预算；模型 ID 仍由 Provider Manifest 或用户配置决定。

无法从 LDR 截图可靠恢复的 Lux、EV、材质参数、UE Actor 或性能收益不得生成。

## 构图辅助

七类辅助线使用归一化坐标定义，由画布按图片尺寸绘制：

- 三分法
- 黄金分割
- 对角线
- 中心构图
- 三角形构图
- 单点透视
- 两点透视

它们只用于人工观察，不自动判断好坏。schema v7 保存当前选择，迁移前自动备份。

## 未改变的边界

- 离线 Mock 不做本地视觉推理。
- 无隐式联网；发送前继续显示数据清单。
- 不新增本地大模型、CUDA、自动显著性、自动分割或泛化总分。
- 原图始终只读。
