# 隐私与联网边界

## 本地数据

GATalk 将项目、原始图片副本、SQLite 数据库、派生分析和导出保存在用户选择的目录。
软件不覆盖导入源文件，不包含遥测、后台上传或自动更新服务。

## API 凭据

API Key 由用户主动输入，可保存到 Windows Credential Manager。GATalk 不把凭据写入
项目、数据库、JSON、日志或 Git。删除项目不会自动删除系统凭据，用户可在供应商设置
中单独删除。

## 网络发送

真实 AI 调用只在用户点击发送并确认清单后发生。清单会说明图片、文字、分辨率、
元数据处理和预计调用次数。外部服务如何保存或训练数据由其条款和用户账号设置决定，
GATalk 无法代替用户确认团队保密政策。

## 导出

外部 AI 审阅包可移除 EXIF、ICC、本地路径和项目名称，并限制图片长边。用户仍应在
上传商业保密内容前确认所属团队政策和目标服务条款。

## 诊断与问题报告

公开 Issue 不应包含 API Key、真实项目、未授权图片、完整请求正文或本机路径。提交前
请使用项目诊断的脱敏报告，并再次人工检查。
