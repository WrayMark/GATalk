# GATalk public roadmap

路线图表达当前方向，不是发布日期承诺。优先级会根据测试反馈、安全性和维护成本
调整。

## 当前：0.18.x Beta 稳定化

- 真实 Windows 10/11、125%/150% 高 DPI 和无 Python 干净机验证。
- OpenAI、Gemini、Claude、Qwen 等供应商的真实账号兼容性测试与失败诊断。
- 简体中文术语收敛；英语、繁中、日语和法语母语审校。
- 旧项目迁移、恢复、锁与异常退出路径的持续验证。
- 安装包签名、发布校验和可重复构建改进。

## 后续候选

- 把作品研究、场景审阅和资产拆分中的证据交接进一步统一。
- 完善审阅任务、版本复查和质量门禁的团队化导出；不提前实现账号与协作服务。
- 扩展资料库到关卡设计、策划等注册域，同时保持现有模块边界。
- 评估更多可替换 AI Provider，不让任何单一服务成为启动条件。
- 在许可证、硬件和实际价值验证后，再评估可选的本地模型与 3D 生产交接。

## 明确不在当前 Beta

视频分析、隐式联网、插件市场、未知代码动态加载、生产级 3D 自动生成、UE 工程
自动修改、CUDA 强制依赖和自动好坏总分不在当前范围。
