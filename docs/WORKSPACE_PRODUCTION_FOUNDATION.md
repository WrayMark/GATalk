# GATalk 工作区生产基础架构

版本：0.15.0  
日期：2026-08-08

## 1. 范围

本轮建立五项跨工作区或生产衔接能力：项目诊断与恢复、全局检索、审阅任务与
质量门禁、资产生产交接、视觉资料板。它们不改变场景分析、作品研究或资产拆分
算法，也不引入网络服务和新运行依赖。

## 2. 工作区目录与检索

`WorkspaceCatalogStore` 只记录用户已打开工作区的入口位置、模块身份、项目身份
和最近打开时间。`GlobalWorkspaceSearch` 在用户发起检索时按需读取入口 JSON，
并以只读方式查询场景项目 SQLite。

检索记录统一包含工作区、项目、对象类型、对象 ID、标题、摘要、标签和版本 ID。
结果打开后由对应工作区定位对象。目录不存在时保留记录供诊断和重定位，不自动
扫描磁盘或复制项目正文。

## 3. 诊断与恢复

诊断识别场景控制、作品研究、资产拆分、参考资料库和作品对照研究入口。检查：

- 入口清单和格式标识；
- 必需目录与场景数据库；
- 清单引用的原始资料和派生产物；
- 目录写入能力、可用空间和恢复点数量。

自动修复只补建空基础目录。恢复点保存入口清单和场景数据库，恢复前建立
`pre_restore` 安全点；恢复源必须位于当前项目 `backups` 内。

## 4. 生产控制

审阅任务保存制作阶段、截止日期和前置任务。存储层校验缺失依赖、自身依赖和
循环依赖。门禁模板只负责建立初始验收项；用户可以修改，AI 不能自动判定人工
验收通过。

资产生产规格绑定资产 ID，记录资产编码、尺寸说明、枢轴、几何、材质、贴图、
LOD、碰撞、Nanite、UE 目录、依赖和交付物。导出按依赖顺序生成 JSON/CSV，
但不会向 UE 工程写入文件。

## 5. 视觉资料板

资料板保存在资料库入口中。卡片可以引用资料条目或保存文字；连线只连接当前
资料板卡片。快照保存结构状态，PNG 只是派生导出。删除资料时同步删除引用卡片
和失效连线，原始资料字节不变。

## 6. 数据版本

- 资产拆分项目：v6，增加 `production_specs`。
- 参考资料库：v3，增加 `visual_boards` 和快照。
- 审阅中心：v2，增加制作阶段、依赖、截止日期和门禁模板身份。

旧数据在升级前复制入口清单到 `backups`。高版本数据继续拒绝写入。

## 7. 后续验收

Windows Alpha 前仍需在真实 125%/150% 高 DPI、中文用户名、无 Python 干净机、
移动项目和异常退出场景中人工验证。真实项目恢复应先使用副本，不以唯一原件做
破坏性试验。
